ITVERSE UPDATED WEBSITE — NOVEMBER 2026

Based on the uploaded ITVerse-main(1).zip.

WHAT'S INCLUDED
- Unified Book 03-inspired pink palette and shared toolbar for 22 reader HTML files.
- Search within book, search results by page, highlighted matching words and jump to page.
- Continue Reading in the Library sidebar (saved automatically).
- Page Bookmarks in reader and Library sidebar.
- Personal Study Notes (add, edit, delete, jump to page).
- Interactive Flashcards tab in Activities & Quizzes; uses multiple-choice questions already present in activities.js.
- Download PDF buttons for 12 books with substantial source lesson content.
- Existing demo Student Sign Up and Login files retained.

PDF AVAILABILITY
The provided ZIP contains several book HTML files that are placeholder shells with almost no lesson content. We did not invent their lessons or create misleading empty PDFs. PDF download is only offered for books with a generated PDF. The PDFs are generated reading copies and may differ visually from the interactive HTML pages.

LOCAL STORAGE
Reading progress, bookmarks and notes are stored locally in each browser, scoped to the demo login email when available. They are not shared across devices and are not secure storage.

INSTALL
Upload the full contents of ITVerse-main to your GitHub repository, keeping the folder structure. Do not upload only the HTML files; the css/, js/, assets/, images/, and pdf-books/ folders are needed.

LIMITATIONS
Some source books are placeholders. Their download button is unavailable until actual book content is supplied. No server-side authentication is included; the existing demo login is browser-only.
