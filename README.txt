ITVerse – SIMPLE STUDENT LOGIN (DEMO ONLY)

1. Copy login.html, signup.html, student-dashboard.html to your website root.
2. Copy css/student-auth.css into your existing css folder.
3. Copy js/student-auth.js into your existing js folder.
4. Keep your existing library.html and activities.html unchanged.
5. Open signup.html, create a demo student account, then log in.
6. Optional: add <a href="login.html">Student Login</a> to your homepage navigation.

IMPORTANT:
- This is NOT secure authentication. Passwords are stored as plain text in browser localStorage.
- Use fictional demo passwords, not real passwords or sensitive personal information.
- Accounts are browser-specific and are not shared across devices.
- Session is stored in sessionStorage and ends when the tab session ends or on logout.
- Existing library.html and activities.html are NOT access-restricted by this starter.
- My Scores is a placeholder; quiz result saving is NOT yet implemented.
- Test on your Vercel site or with a local web server. Some browsers restrict file:// storage.
