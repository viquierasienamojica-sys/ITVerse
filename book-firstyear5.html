Binary information in digital computers is stored in memory or procesrso registers. Registers contain either data or control information. Control information Is a bit or a group of bits used to specify the sequence of command signals needed for manipulation of the data in other registers. Data are numbers and other binary-coded information that are operated on to achieve required computational results.

Everything in a computer is 0 and 1. Even pictures, music, and videos are stored as binary.

REGISTERS

Register = Very small, very fast storage inside the CPU.

Holds data temporarily while CPU is working

Example: Accumulator, Program Counter, Instruction Register

Made of flip-flops

DATA vs CONTROL INFORMATION

Data: What is processed. Example: Numbers, Letters

Control Information: How to process it. Example: Instruction to ADD, MOVE, STORE

Analogy: Data = Ingredients, Control = Recipe

The data types found in the registers of digital computers may be classified as being one of the following categories:{1) numbers used in arithmetic computations,(2) letters of the alphabet used in data processing. and(3) {3} other discrete symbols used for specific purposes.

3 Categories: Numbers, Letters, Symbols. All are stored as binary.

All types of data, except binary numbers, are represented in computer registers in binary coded form. This is because registers are made up of flip-flops and flip-flops are two-state devires that can store only 1's and O's. The binary number system is the most natural system to use in a digital computer. But sometimes it is convenient to employ different number systems, espedally the decimal number system, since it is used by people to perform arithmetic computations.

Flip-flop = ON (1) or OFF (0). Like a light switch. Computer has billions of switches.

NUMBER SYSTEMS

There are four common number systems that is used today. These are:

Base = How many digits are used.

Binary = Base 2

BINARY SYSTEM:

The binary system is a base-2 system.

There are 2 distinct digits (0 and 1) to represent any quantity.

For an n-digit number, the value of a digit in each column depends on its position.

The weights are based on powers of 2.

Powers of 2: 1, 2, 4, 8, 16, 32, 64, 128, 256, 512, 1024

Example: 101 = 4 + 0 + 1 = 5

DECIMAL SYSTEM:

The decimal system is a base-10 system.

There are 10 distinct digits (0 to 9) to represent any quantity.

For an n-digit number, the value that each digit represents depends on its weight or position.

The weights are based on powers of 10.

Powers of 10: 1, 10, 100, 1000

Example: 345 = 300 + 40 + 5. This is what humans use daily.

OCTAL SYSTEM:

Octal and hexadecimal systems provide a shorthand way to deal with the long strings of 1"s and 0"s in binary.

Octal is base-8 system using the digits 0 to 7.

Why Octal? Because 8 = 2³. So 3 binary digits = 1 octal digit. Shorter to write.

HEXADECIMAL SYSTEM:

Hexadecimal is a base-16 system.

It contains the digits 0 to 9 and the letters A to F (16 digit values).

The letters A to F represent the unit values 10 to 15.

This system is often used in programming as a condensed form for binary numbers

Why Hex? Because 16 = 2⁴. So 4 binary digits = 1 hex digit. Used for colors, memory addresses.

Example: #FF0000 = Red in HTML. FF = 255.

ADDITIONAL LESSON: NUMBER SYSTEMS AND DATA REPRESENTATION

IMPORTANCE OF NUMBER SYSTEMS IN COMPUTING

Number systems are essential in computer science because they provide a way to represent, store, and process information. Computers use electronic circuits that recognize two basic states: ON and OFF. These states are represented by the binary digits 1 and 0.

Although people commonly use the decimal system, computers use binary internally. Other number systems, such as octal and hexadecimal, make binary information easier for people to read and understand.

Why are number systems important?

Data Storage – Computers store numbers, letters, pictures, and other information using binary codes.

Data Processing – The CPU performs calculations and logical operations using binary values.

Programming – Programmers use binary and hexadecimal when working with memory, machine instructions, and debugging.

Networking – Binary values are used in IP addresses and other network-related information.

Digital Electronics – Circuits use binary states to represent information and perform operations.

Example:

When a user types the number 5 on a keyboard, the computer does not simply store it as the written symbol. It converts the character into a code represented by binary bits.

The same principle applies to letters, symbols, pictures, and other digital information.

Remember: Humans commonly communicate using decimal numbers, while digital computers process information using binary.

BITS, NIBBLES, BYTES, AND WORDS

A computer represents information using bits. A bit is the smallest unit of digital data and can have only one of two values: 0 or 1.

Several bits can be combined to represent larger amounts of information.

1. Bit

The smallest unit of computer data.

Can contain either 0 or 1.

Example: 1

2. Nibble

A group of 4 bits.

One hexadecimal digit can represent one nibble.

Example: 1010

3. Byte

A group of 8 bits.

Commonly used as a basic unit of digital storage.

Example: 01000001

4. Word

A group of bits processed together by a computer's processor.

Word size depends on the computer architecture.

Common examples include 16-bit, 32-bit, and 64-bit systems.

CONVERTING DECIMAL FRACTIONS TO BINARY

So far, most examples have used whole numbers. However, computers also represent values that contain fractional parts.

A decimal fraction is a number with digits after the decimal point.

To convert a decimal fraction into binary, repeatedly multiply the fractional part by 2. Record the whole-number result of each multiplication. Continue until the fraction becomes zero or until the desired number of binary digits has been produced.

Steps:

Separate the whole-number part from the fractional part.

Multiply the fractional part by 2.

Record the whole-number result.

Use the remaining fractional part for the next multiplication.

Read the recorded whole-number results from top to bottom.

SIGNED AND UNSIGNED BINARY NUMBERS

Binary numbers can represent positive numbers and, depending on the representation method, negative numbers.

Two common categories are unsigned and signed numbers.

1. Unsigned Binary Numbers

Unsigned binary numbers represent only zero and positive values.

For example, using 8 bits:

00000000 = 0

00000001 = 1

00000101 = 5

00001010 = 10

11111111 = 255

An 8-bit unsigned number can represent values from 0 to 255.

2. Signed Binary Numbers

Signed binary numbers can represent both positive and negative values.

One commonly used representation is two's complement.

In an 8-bit two's complement system:

00000000 = 0

00000001 = +1

00000101 = +5

11111111 = -1

11111110 = -2

11111011 = -5

An 8-bit two's complement number can represent values from -128 to +127.

Difference Between Signed and Unsigned

FeatureUnsignedSigned (Two's Complement)
RepresentsZero and positive valuesPositive and negative values
8-bit minimum0-128
8-bit maximum255127
Negative valuesNoYes

Why is this important?

Computers must know whether a group of bits represents an ordinary positive quantity or a signed value. The interpretation affects the result of calculations.

For example, the same bit pattern can represent different values depending on whether it is treated as signed or unsigned.

UNDERSTANDING TWO'S COMPLEMENT

Two's complement is a method used by computers to represent signed integers.

It allows a computer to perform addition and subtraction using binary arithmetic circuits.

How to Find the Two's Complement

Write the binary number.

Change every 0 to 1 and every 1 to 0. This is called finding the one's complement.

Add 1 to the result.

Example: Find the two's complement of 00000101.

Original number:

00000101

Step 1: Invert every bit.

11111010

Step 2: Add 1.

11111010 +00000001 =11111011

Therefore, the 8-bit two's complement representation of -5 is:

11111011

Understanding the Result

In an 8-bit signed two's complement system, 11111011 represents -5.

The leftmost bit is called the sign bit in this representation:

0 generally indicates a nonnegative value.

1 indicates a negative value.

Example: Represent -10 using 8 bits.

Positive 10:

00001010

Invert the bits:

11110101

Add 1:

11110101 +00000001 =11110110

Therefore:

-10 = 11110110 in 8-bit two's complement.

Important Reminder:

The number of bits matters. Always use the required bit width when finding the two's complement representation.

BINARY OVERFLOW AND CARRY

Overflow happens when the result of an arithmetic operation is too large or too small to be represented using the available number of bits.

The available bit width determines the range of values a computer can store.

Unsigned Overflow Example

Suppose an 8-bit unsigned system performs:

255 + 1

The binary representation of 255 is:

11111111

Adding 1 gives a result that requires 9 bits:

11111111 +00000001 =100000000

However, the system can store only 8 bits. The extra carry bit cannot fit in the 8-bit result.

If only the lower 8 bits are kept, the result becomes:

00000000

This is an example of unsigned overflow.

Signed Overflow Example

In an 8-bit signed two's complement system, the maximum positive value is 127.

Consider:

127 + 1

Binary representation:

01111111 +00000001 =10000000

The result is outside the valid positive range of the 8-bit signed system. This is signed overflow.

Carry vs. Overflow

These terms are related but do not mean exactly the same thing.

Carry is a bit produced when an addition exceeds the value of a single binary position.

Overflow occurs when the mathematical result cannot be represented within the allowed range of the number format.

Why should programmers understand overflow?

Understanding overflow helps prevent incorrect calculations in software, especially when working with limited storage sizes, counters, measurements, and numerical data.

Computers can store more than numbers and text. They can also represent pictures, sounds, and videos using binary information.

A digital image is commonly made up of tiny units called pixels.

Each pixel represents a small part of an image.

The color of a pixel can be represented using numerical values.

In an RGB color model, the three main color channels are:

2. Digital Audio

Digital audio represents sound through samples.

A microphone captures sound waves, and an audio system converts them into digital information.

Two important concepts are:

Sample Rate – The number of audio samples taken per second.

Bit Depth – The number of bits used to represent each audio sample.

A higher sample rate or bit depth can increase the amount of data required to store audio.

3. Digital Video

Digital video consists of a sequence of images called frames.

When frames are displayed rapidly, they create the appearance of movement.

Important video concepts include:

Resolution – The number of pixels used in each frame.

Frame Rate – The number of frames displayed per second.

Color Depth – The number of bits used to represent color information.

Compression – A method used to reduce file size.

Example:

A video recorded at 1920 × 1080 resolution contains 1,920 pixels across and 1,080 pixels vertically in each frame.

Digital images, audio, and videos all depend on binary representation.

PAGE 12 – DATA COMPRESSION AND FILE FORMATS

Digital files can become very large, especially when they contain high-quality images, audio, and videos.

Data compression reduces the amount of storage space required by a file.

There are two main types of compression.

1. Lossless Compression

Lossless compression reduces file size without permanently removing original information.

The original data can be reconstructed exactly after decompression.

Examples include:

ZIP

PNG

FLAC

Advantages:

Preserves original information.

Useful for documents and files that must remain exact.

Allows the original data to be recovered.

2. Lossy Compression

Lossy compression reduces file size by removing some information that may be less noticeable to users.

Examples include:

JPEG

MP3

Some video compression formats

Advantages:

Can produce much smaller files.

Useful for online images, music, and videos.

Helps reduce storage and transmission requirements.

Disadvantages:

Some original information is permanently lost.

Repeated compression may reduce quality further.

PRACTICAL APPLICATIONS OF NUMBER SYSTEMS

Number systems are used in many areas of modern technology.

1. Computer Programming

Programmers may use hexadecimal values to represent data, memory addresses, and machine-related information.

Example:

0x1A represents a hexadecimal value.

2. Web Design

Web designers use hexadecimal color codes to specify colors in websites.

Examples:

#FFFFFF – White

#000000 – Black

#FF0000 – Red

#0000FF – Blue

3. Networking

IP addresses are represented in decimal for easier reading, but computers process their binary values.

Example:

192.168.1.1

Each decimal section represents 8 bits in an IPv4 address.

4. Digital Electronics

Electronic circuits use binary states to represent information.

A circuit can interpret a low voltage as 0 and a high voltage as 1, depending on its design.

5. Digital Clocks and Calculators

Some digital devices use BCD to represent decimal digits.

BCD makes it possible to display decimal numbers using electronic circuits.

6. Computer Memory

Memory addresses are often written in hexadecimal because it is shorter and easier to read than long binary sequences.

7. Data Communication

Computers exchange information through networks using binary data. Text, images, audio, and other files are encoded before transmission.

8. Robotics and Automation

Digital systems use binary signals to receive sensor information and control motors, lights, and other devices.

FINAL SUMMARY

Number systems and data representation are fundamental topics in computer science. They explain how computers represent, store, and process different kinds of information.

The binary system is the primary number system used by digital computers because electronic circuits can represent two basic states. Decimal, octal, and hexadecimal systems provide other ways to express numerical values.

Bits, nibbles, bytes, and words describe different groups of digital information. Binary arithmetic allows computers to perform calculations, while signed number representations such as two's complement allow them to work with negative integers.

Character encoding systems such as ASCII and Unicode allow computers to represent letters, numbers, and symbols. Images, audio, and videos are also represented digitally through binary information.

Logic gates provide the basic operations used in digital circuits. Data compression helps reduce file sizes, and different file formats are designed for different purposes.

Understanding these concepts helps students develop a strong foundation in programming, computer hardware, networking, digital electronics, and information technology.
