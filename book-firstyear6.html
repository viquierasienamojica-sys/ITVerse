Introduction to Operating System

An operating system acts as an intermediary between the computer hardware and the user. It provides a controlled interface between users/applications and computer hardware and manages system resources.

It provides an environment in which users can execute programs conveniently and efficiently.

The operating system's kernel remains active when the computer is running and manages system resources and provides essential services to programs.

It assigns resources such as memory, processors, and input/output devices to processes that need them.

An OS is system software that acts as an intermediary between user and computer hardware. It manages all hardware resources and provides services to application programs.

WHAT IS OS IN SIMPLE WORDS

OS = Manager of the Computer.

Without OS, you cannot open Chrome, Word, games.

OS is not just the desktop screen. It includes kernel, services, drivers, file systems, user accounts, logs, security settings.

Example: When you click an icon, OS tells CPU to read command, pull data from RAM, process it, and send result to monitor.

Operating System and User Interaction

Every general-purpose computer consists of hardware, an operating system, system programs and application programs.

The hardware includes the CPU, main memory, storage devices, and I/O and peripheral devices.

System programs include compilers, assemblers, loaders, editors, utilities, and command interpreters.

Application programs are user-level software that perform specific tasks.

Layer order: User → Application Programs → System Programs → OS → Hardware. The OS is the layer between hardware and software.

HARDWARE vs SYSTEM vs APPLICATION

Hardware: CPU, RAM, Storage, Keyboard, Monitor

System Programs: Compiler, Assembler, Loader, Editor, Utility

Application Programs: Word, Excel, Chrome, Games, Spotify

OS: Windows, macOS, Linux - sits in middle

Operating System and User Interaction

The OS kernel remains active while the computer is running and manages hardware resources and provides services to system and application programs. The OS itself is not only a user interface. Instead, it provides an interface for user interaction, typically through:

Command-Line Interface (CLI), (e.g., Bash, PowerShell)

Graphical User Interface (GUI), (e.g., Windows desktop, macOS Finder)

Kernel is the core of OS. It controls low-level access to CPU, memory, storage, devices, and processes. Applications request work from kernel through controlled interfaces instead of touching hardware directly.

CLI EXPLAINED

CLI = Command-Line Interface - Text-based way to interact. Instead of clicking buttons, you type a command and press Enter.

Examples: Bash, PowerShell, Command Prompt, Terminal

GUI = Graphical User Interface - Lets people interact through visual elements such as windows, icons, menus, buttons, and dialogs.

Kernel runs in privileged mode and has complete access to system hardware and memory. All system programs, including shell, depend on kernel. Kernel is the persistent portion that remains in memory.

TYPES OF KERNEL

Monolithic Kernel: All services in one - Fast, but if one crashes, all crash. Example: Linux

Microkernel: Small core, other services outside - More stable, slower. Example: Minix

Hybrid Kernel: Mix of both. Example: Windows, macOS

Goals of Operating System

The goals of an operating system are:

Primary Goals

The primary goals of an operating system (OS) are to provide an easy-to-use and convenient environment for executing user programs.

User Convenience: It should be easy to use, providing a user-friendly interface and making it simple to interact with the system.

Program Execution: It facilitates the execution of user programs by providing the necessary environment and services for them to run.

Resource Management: The OS manages and allocates the computer's resources, including the CPU, memory, disk storage and input/output devices, to ensure fair utilization.

Security: The OS protects the system and user data from unauthorized access, ensuring confidentiality, integrity and availability of information.

Two main goals: Resource Management - manages CPU, memory, storage, I/O to ensure efficient and fair allocation. User Interface - provides interface to interact.

Secondary Goals

Secondary goals of an operating system focus on improving overall system performance and stability. They ensure efficient use of resources and make the system reliable and robust.

Efficient Resource Utilization: It should aim to maximize the performance and utilization of computer resources like CPU, Memory and I/O devices, ensuring that the system runs smoothly and efficiently.

Reliability: The OS should be robust and reliable, able to handle errors and exceptions gracefully and maintain stable system operation.

OS goals: Maximum CPU utilization, Less process starvation, Higher priority job execution.

Components of Operating System

Two commonly discussed parts of an operating system are the kernel and the shell.

Shell is a command interpreter that provides an interface for users to interact with the operating system. It accepts user commands, interprets them, and invokes the appropriate programs or system services.

Kernel is the core component of the operating system. It provides the interface between software and hardware and manages resources such as the CPU, memory, and I/O devices.

Flow: User → Shell → Kernel → Hardware. Shell is interface between user and kernel.

HOW AN OPERATING SYSTEM STARTS

An operating system does not begin working only when the desktop appears on the screen. Several important processes happen when a computer is turned on. This process is commonly called the boot process.

The boot process prepares the computer hardware and loads the operating system into memory so that the user can start working.

Steps in the Boot Process

1. Power On

When the user presses the power button, the computer receives electrical power. The CPU and other hardware components begin their startup activities.

2. BIOS or UEFI Initialization

BIOS (Basic Input/Output System) or UEFI (Unified Extensible Firmware Interface) is firmware that helps initialize the computer hardware during startup.

It performs basic checks and identifies important hardware components.

3. POST (Power-On Self-Test)

POST checks whether essential hardware components are functioning properly.

Examples of components checked include:

RAM

Keyboard

Processor

Storage devices

Other essential hardware

If a problem is detected, the computer may display an error message or produce a warning sound, depending on the system.

4. Bootloader Execution

The bootloader is a program responsible for locating and starting the operating system.

It helps transfer control to the operating system's kernel.

5. Kernel Loading

The kernel is loaded into main memory. It begins managing system resources such as the CPU, memory, and connected devices.

6. System Services Initialization

The operating system starts essential background services, device drivers, and other system components.

7. Login Screen or Desktop Appears

After the required startup processes are completed, the user can log in or access the desktop environment.

Example

When a student turns on a laptop, the computer first checks its hardware, loads the operating system, starts important services, and finally displays the login screen.

Importance of the Boot Process

The boot process ensures that the hardware and operating system are prepared before the user begins using applications.

Without a proper startup process, the computer may not be able to load the operating system or function correctly.

PROCESS MANAGEMENT IN OPERATING SYSTEMS

Process management is one of the major responsibilities of an operating system.

A process is a program that is currently being executed. When a user opens an application, the operating system creates and manages the process needed to run it.

For example, opening a web browser creates a process that allows the browser to perform its tasks.

Program vs. Process

A program and a process are related, but they are not exactly the same.

Main Responsibilities of Process Management

1. Process Creation

The operating system creates processes when applications or system tasks need to run.

2. Process Scheduling

The operating system determines which process should receive CPU time.

3. Process Execution

The CPU executes instructions belonging to the selected process.

4. Process Synchronization

The operating system helps coordinate processes that need to share information or resources.

5. Process Termination

When a process finishes or is stopped, the operating system releases the resources associated with it.

Examples of Processes

Opening a browser

Playing music

Printing a document

Running a calculator

Downloading a file

Performing a system update

Why Is Process Management Important?

A computer may run many applications at the same time. Process management helps organize their activities and prevents one application from unnecessarily interfering with another.

It also helps the operating system distribute available CPU time and other resources efficiently.

PROCESS STATES AND PROCESS CONTROL

During execution, a process moves through different states. These states describe what the process is currently doing and whether it is ready to use the CPU.

Five Common Process States

1. New

The process is being created. The operating system prepares the necessary information and resources.

2. Ready

The process is prepared to execute but is waiting for CPU time.

3. Running

The process is currently being executed by the CPU.

4. Waiting or Blocked

The process cannot continue until a particular event occurs. For example, it may be waiting for input from a keyboard or completion of a disk operation.

5. Terminated

The process has finished executing or has been stopped.

CPU SCHEDULING

CPU scheduling is the process of selecting which ready process should be executed by the CPU next.

Because multiple processes may need the CPU, the operating system uses scheduling methods to organize execution.

The goal is to use CPU resources efficiently while providing good system performance.

Common CPU Scheduling Algorithms

1. First-Come, First-Served (FCFS)

The process that arrives first is executed first.

Example:

2. Shortest Job First (SJF)

The process with the shortest CPU burst time is selected first.

Example:

If all processes arrive at the same time, the execution order is:

This method can reduce average waiting time, but longer processes may wait for a long period.

3. Priority Scheduling

Each process is assigned a priority. The operating system selects a process based on its priority level.

A process with a higher priority may be executed before a process with a lower priority.

4. Round Robin Scheduling

Each process receives a fixed amount of CPU time called a time quantum.

When the time quantum ends, the process may return to the ready queue if it has not finished.

This method is commonly discussed in time-sharing systems.

CPU scheduling allows multiple processes to share the processor. It helps the computer remain responsive while applications and background tasks are running.

MULTITASKING, MULTIPROGRAMMING, AND MULTITHREADING

Modern operating systems support different methods of managing multiple activities.

These methods help computers perform several operations efficiently.

1. Multitasking

Multitasking allows the operating system to manage multiple tasks during the same period.

For example, a student may:

Listen to music.

Type a document.

Download a file.

Browse the internet.

The operating system coordinates these activities by allocating CPU time and other resources.

Multitasking does not always mean that every task executes at the exact same moment. On a single CPU core, the operating system can rapidly switch between tasks.

2. Multiprogramming

Multiprogramming allows several programs to be kept in main memory so that the CPU can switch to another program when one is waiting for an input/output operation.

Its main purpose is to improve CPU utilization.

For example, when one program waits for a file to load, the CPU may execute another ready program.

3. Multithreading

A thread is a smaller unit of execution within a process.

A single process may contain multiple threads that perform different activities.

Example: A web browser may use separate threads for:

Processing user interactions

Loading website information

Performing background activities

Updating parts of the interface

When a student attends an online class, the computer may run a video application, maintain an internet connection, play audio, and process keyboard input.

MEMORY MANAGEMENT

Memory management is an important function of an operating system.

It controls how the computer's main memory, especially RAM, is allocated and used by running programs.

Each application needs memory to store instructions and data while it is running.

Main Functions of Memory Management

1. Memory Allocation

The operating system provides memory space to processes that need it.

2. Memory Deallocation

When a process finishes or no longer needs a memory area, the operating system makes that space available for other uses.

3. Memory Tracking

The operating system keeps track of which areas of memory are being used and which are available.

4. Memory Protection

It helps prevent one process from accessing memory that belongs to another process without permission.

5. Memory Organization

The operating system organizes memory so that processes can use available space efficiently.

RAM and Its Importance

RAM stands for Random Access Memory.

It temporarily stores information needed by currently running programs.

Examples of information stored in RAM include:

Open application data

Active documents

Temporary program information

Parts of the operating system

Data currently being processed

RAM is volatile memory, which means its contents are normally lost when the computer loses power.

What Happens When RAM Is Almost Full?

When available RAM becomes limited, the operating system may need to manage memory more carefully.

It may move less frequently used memory pages to secondary storage through a mechanism called virtual memory.

This can allow applications to continue operating, although accessing secondary storage is generally slower than accessing RAM.

Example

A student opens a browser, a presentation application, and a music player.

Each application requires memory. The operating system allocates available RAM to these processes and manages their memory use.

Importance of Memory Management

Proper memory management helps prevent applications from interfering with one another and supports stable system operation.

VIRTUAL MEMORY AND MEMORY ALLOCATION

Virtual memory is a memory management technique that gives processes the appearance of having their own large, continuous memory spaces.

It allows the operating system to use secondary storage as support when physical RAM is insufficient for the current memory demands.

How Virtual Memory Works

The operating system divides memory into manageable units.

In a common virtual memory system, these units are called pages.

A process uses virtual addresses, and the operating system translates them into physical memory locations when needed.

When a required page is not currently in RAM, the operating system may need to retrieve it from secondary storage. This event is called a page fault.

A page fault is not automatically an error. It is a normal part of virtual memory operation, although excessive page faults can slow down a computer.

Important Terms

1. Virtual Address

An address used by a process within its virtual memory space.

2. Physical Address

The actual location in the computer's physical memory.

3. Page

A fixed-size block of virtual memory.

4. Page Frame

A fixed-size block of physical memory that can hold a page.

5. Page Fault

An event that occurs when a process tries to access a page that is not currently available in physical memory.

6. Swapping

A general term associated with moving memory contents between RAM and secondary storage. Modern systems may use paging rather than moving entire processes.

Advantages of Virtual Memory

Allows programs to use larger address spaces.

Helps isolate processes.

Supports efficient memory allocation.

Allows multiple applications to run even when physical RAM is limited.

Limitations

Secondary storage is slower than RAM.

Excessive paging can reduce performance.

It requires proper memory management by the operating system.

Example

A computer with limited RAM may still run several applications because the operating system can manage their memory using virtual memory.

However, if too much data must be moved between RAM and storage, the computer may become noticeably slower.

Main I/O Management Activities

3. Buffering

SECURITY AND USER ACCOUNT MANAGEMENT

Security is an important part of an operating system.

The operating system helps protect files, applications, user accounts, and system resources from unauthorized access.

It provides mechanisms that help ensure that only permitted users and programs can perform certain actions.

1. User Authentication

Authentication verifies the identity of a user.

Common authentication methods include:

Passwords

PINs

Fingerprint recognition

Facial recognition

Security keys

2. User Authorization

Authorization determines what an authenticated user is allowed to access or perform.

For example, an administrator may have permission to install software and change system settings, while a standard user may have more limited privileges.

3. Access Control

Access control determines which users or programs can access particular files, folders, and system resources.

4. User Accounts

Operating systems commonly provide different account types.

Administrator Account

An administrator account has elevated privileges and can make important system changes.

Standard User Account

A standard user can perform ordinary tasks but may not be allowed to make certain system-level changes.

Guest or Temporary Account

Some systems support limited accounts for temporary access.

5. System Updates

Operating system updates may include:

Security improvements

Bug fixes

Compatibility updates

Performance improvements

New features

6. Firewall and Security Tools

A firewall helps control network traffic according to security rules.

Operating systems may also include security tools that help detect threats and protect stored information.

Good Security Practices

Use strong and unique passwords.

Keep the operating system updated.

Lock the computer when not in use.

Avoid opening suspicious attachments.

Download software from trusted sources.

Use appropriate account permissions.

Back up important files.

Importance of Operating System Security

Operating system security helps protect the confidentiality, integrity, and availability of information.

It also reduces the risk of unauthorized changes and misuse of computer resources.

NETWORKING AND COMMUNICATION IN OPERATING SYSTEMS

Modern operating systems include networking features that allow computers to communicate with other devices.

Networking makes it possible to share files, access websites, send messages, use online applications, and connect to shared resources.

Main Networking Functions of an OS

1. Network Connection Management

The operating system manages connections through wired or wireless network adapters.

2. Data Transmission

It supports the sending and receiving of information through network protocols.

3. Network Configuration

Users can configure network settings such as IP addresses, Wi-Fi connections, and other connection details.

4. Resource Sharing

The operating system may allow users to share printers, folders, and other network resources.

5. Network Security

It provides tools and settings that help protect network connections.

Common Network Technologies

Ethernet

A wired networking technology commonly used in local area networks.

Wi-Fi

A wireless networking technology that allows devices to connect without physical network cables.

Bluetooth

A short-range wireless technology used to connect devices such as keyboards, speakers, and headphones.

Cellular Networks

Wireless networks used by mobile devices to access communication and internet services.

Important Network Terms

IP Address

A numerical address used to identify a device on an IP network.

DNS (Domain Name System)

A system that translates domain names into IP addresses.

TCP (Transmission Control Protocol)

A transport protocol that provides reliable, ordered delivery of data.

UDP (User Datagram Protocol)

A transport protocol that sends data without providing the same delivery guarantees as TCP.

Example: Opening a Website

The user opens a web browser.

The user enters a website address.

The operating system and network software help establish communication.

DNS helps identify the server's IP address.

Network protocols support the exchange of information.

The browser receives and displays the website.

Importance of Networking Support

Networking features allow computers to communicate and share information, making modern digital services possible.

VIRTUALIZATION AND CLOUD COMPUTING

Virtualization is a technology that allows one physical computer to run multiple virtual computing environments.

A virtual machine is a software-based computer that behaves like a separate physical computer.

Each virtual machine can have its own operating system and applications.

What Is a Virtual Machine?

A virtual machine (VM) is an environment that uses virtualized hardware resources.

It can run an operating system such as Windows or Linux without requiring a separate physical computer for every system.

Hypervisor

A hypervisor is software that creates and manages virtual machines.

It allocates physical resources such as CPU time, memory, and storage to virtual machines.

Types of Hypervisors

Type 1 Hypervisor

Runs directly on the physical hardware.

It is commonly used in server environments.

Type 2 Hypervisor

Runs as an application on top of an existing operating system.

It is commonly used for testing, learning, and personal computing.

Advantages of Virtualization

Allows multiple operating systems on one physical machine.

Helps use hardware resources efficiently.

Provides separate environments for testing.

Makes system deployment and management more flexible.

Can reduce the need for additional physical computers.

What Is Cloud Computing?

Cloud computing provides computing resources and services through a network, commonly the internet.

These services may include storage, applications, databases, and processing power.

Common Cloud Service Models

1. Infrastructure as a Service (IaaS)

Provides computing infrastructure such as virtual machines, storage, and networking.

2. Platform as a Service (PaaS)

Provides an environment for developing, testing, and deploying applications.

3. Software as a Service (SaaS)

Provides applications that users access through the internet.

Examples of Cloud Services

Online document editors

Cloud storage

Online email services

Web-based collaboration tools

Virtual servers

Virtualization vs. Cloud Computing

Virtualization creates virtual computing environments, while cloud computing delivers computing resources as services.

They are related technologies, but they are not the same.

OPERATING SYSTEM ERRORS, MAINTENANCE, AND TROUBLESHOOTING

An operating system manages many hardware and software activities. Because of this, different problems may occur during normal computer use.

Troubleshooting is the process of identifying the cause of a problem and finding an appropriate solution.

Common Operating System Problems

1. Slow Performance

Possible causes:

Too many applications running

Limited available RAM

Low storage space

Background processes

Outdated software

Possible solutions:

Close unnecessary applications.

Restart the computer when appropriate.

Remove unnecessary files.

Check which applications are using system resources.

Install appropriate updates.

2. Application Not Responding

An application may stop responding because of software errors, resource limitations, or other problems.

Possible solutions:

Wait briefly to see whether it recovers.

Close the application using the operating system's task management tools.

Reopen the application.

Check for available updates.

3. Driver Problems

A device may not work correctly when its driver is missing, outdated, or incompatible.

Possible solutions:

Check the device status.

Install a compatible driver.

Use the device manufacturer's official support resources.

4. Storage Problems

A computer may become difficult to use when its storage is almost full.

Possible solutions:

Remove unnecessary files.

Uninstall applications that are no longer needed.

Move personal files to appropriate storage.

Use built-in storage management tools.

5. Operating System Startup Problems

The computer may fail to load the operating system correctly.

Possible causes include:

Damaged system files

Storage device problems

Incorrect startup settings

Incomplete updates

Hardware issues

Appropriate recovery tools may help diagnose and repair some startup problems.

Preventive Maintenance

Preventive maintenance helps reduce the possibility of system problems.

Recommended practices include:

Install operating system updates.

Keep enough free storage space.

Use reliable security software.

Back up important data.

Avoid installing unknown applications.

Keep device drivers compatible.

Shut down or restart the computer properly.

Importance of Maintenance

Regular maintenance helps improve reliability, protect information, and extend the useful life of a computer system.

FINAL SUMMARY

An operating system is an essential type of system software that manages computer hardware and provides services to applications and users.

It acts as an intermediary between the user and the computer hardware. It provides an environment where programs can execute and manages important resources such as the CPU, memory, storage, and input/output devices.

The operating system performs several major functions, including process management, memory management, file system management, device management, security, and I/O management.

It also supports multitasking, networking, user accounts, and other services that make modern computers useful and convenient.

The boot process prepares the computer for operation, while the kernel manages important low-level system activities. The shell provides an interface through which users can interact with the operating system.

Different operating systems are designed for different environments. Windows, macOS, Linux, Unix, Android, iOS, and ChromeOS provide different features and capabilities.

Understanding operating systems is important because they are used in education, business, healthcare, communication, entertainment, and many other fields.

KEY TAKEAWAY: An operating system is more than the desktop or screen that users see. It is the software responsible for coordinating computer resources, managing programs, controlling devices, protecting information, and providing the environment needed for applications to function.
