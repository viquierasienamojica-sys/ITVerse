CHAPTER 1 · Introduction to HTML

1.1 What Is HTML?

HTML stands for HyperText Markup Language. It describes the meaning and organization of content on a webpage. A browser reads HTML and constructs a document structure that can be styled with CSS and made interactive with JavaScript.

HTML Example

<h1>Welcome to My Website</h1>
<p>This is my first paragraph.</p>

Understanding the Example

Read the code from top to bottom. Notice how each opening tag identifies a piece of content, how attributes add information, and how nested elements establish relationships. The browser interprets this markup as a structured document rather than simply displaying the tag characters. When applying this pattern in a real website, replace the sample words and file names with your own content. Save the document as an HTML file and open it in a modern browser to inspect the result. For images, store the image file separately so it can be replaced without rewriting the lesson.

Practical Design Note

Use the most meaningful HTML element for the job. Avoid selecting tags only because of their default appearance. Add CSS for layout and color, and check that the content remains understandable when styling is disabled. This separation makes a project easier to revise and maintain. 1.4 Basic HTML Document Structure

A complete document begins with a doctype declaration, followed by the html root element. The head contains metadata, while the body contains visible content. The lang attribute identifies the document language.

HTML Example

<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Student Page</title>
</head>

A student profile can use a main heading, a figure for a profile image, and sections for academic details and interests. Use neutral, meaningful markup so the content remains understandable without visual styling.

HTML Example

<main>
<h1>Student Profile</h1>
<figure><img src="student.jpg" alt="Student portrait"></figure>
<section><h2>About Me</h2><p>BSIT student.</p></section>
</main>

Understanding the Example

Read the code from top to bottom. Notice how each opening tag identifies a piece of content, how attributes add information, and how nested elements establish relationships. The browser interprets this markup as a structured document rather than simply displaying the tag characters. When applying this pattern in a real website, replace the sample words and file names with your own content. Save the document as an HTML file and open it in a modern browser to inspect the result. For images, store the image file separately so it can be replaced without rewriting the lesson.

Practical Design Note

Use the most meaningful HTML element for the job. Avoid selecting tags only because of their default appearance. Add CSS for layout and color, and check that the content remains understandable when styling is disabled. This separation makes a project easier to revise and maintain. 6.3 Creating a Navigation Menu

A navigation menu should group important links and describe where each one leads. A list inside nav is a common pattern. Keep the order consistent across pages and ensure links can be reached using a keyboard.

HTML Example

<nav aria-label="Main menu">
<ul>
<li><a href="index.html">Home</a></li>
<li><a href="books.html">Books</a></li>
<li><a href="about.html">About</a></li>
</ul>
</nav>

6.5 Complete Semantic HTML Page

A complete semantic document combines metadata, navigation, content landmarks, structured sections, and a footer. Use it as a reusable starting point, then adjust the content and CSS to fit a specific project.

HTML Example

<!doctype html>
<html lang="en">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>Learning Portal</title>
</head>
<body>
<header><h1>Learning Portal</h1></header>
<nav aria-label="Primary"><a href="index.html">Home</a></nav>
<main><article><h2>HTML Lesson</h2><p>Welcome!</p></article></main>
<footer><p>Learning Portal</p></footer>
</body>
</html>

Understanding the Example

Read the code from top to bottom. Notice how each opening tag identifies a piece of content, how attributes add information, and how nested elements establish relationships. The browser interprets this markup as a structured document rather than simply displaying the tag characters.
