IT Glossary

Browse 114 computing terms with simple explanations. Use the search bar to find a term.

Access Control

Rules that determine who can view or use a resource.

Accessibility

Designing technology so people with different abilities can use it.

Algorithm

A set of steps used to solve a problem or complete a task.

API

A set of rules that lets software applications communicate.

Application Software

Programs that help users perform specific tasks.

Artificial Intelligence

Technology that enables computers to perform tasks associated with human intelligence.

Authentication

Checking whether a user is who they claim to be.

Authorization

Deciding what an authenticated user is allowed to do.

Backend

The part of a system that handles server-side logic and data.

Backup

A copy of data kept in case the original is lost or damaged.

Bandwidth

The amount of data a connection can transfer in a given time.

Binary

A number system that uses only 0 and 1.

BIOS

Firmware that helps start a computer and initialize hardware.

Bit

The smallest unit of digital data, either 0 or 1.

Bluetooth

A wireless technology for connecting devices over short distances.

Boolean

A data type with two possible values: true or false.

Browser

Software used to access and view websites.

Bug

An error in software that causes incorrect behavior.

Byte

A unit of digital data commonly made of eight bits.

Cache

Temporary storage that helps access frequently used data faster.

Client

A device or program that requests services from a server.

Cloud Computing

Using computing resources and services over a network.

Compiler

A program that translates source code into another form, often machine code.

Computer Network

Connected devices that share information and resources.

Cookie

A small piece of data a website stores in a browser.

CPU

The main processor that executes program instructions.

CSS

A language used to style and arrange web pages.

Cybersecurity

Practices used to protect systems, networks, and data from attacks.

Data

Raw facts or values that can be processed.

Database

An organized collection of information.

Database Management System

Software used to create, manage, and query databases.

Debugging

Finding and fixing errors in a program.

Deployment

Making a website or application available for use.

Device Driver

Software that allows an operating system to communicate with hardware.

DNS

A system that translates domain names into IP addresses.

Domain Name

A human-readable address used to find a website.

Download

Copying data from a remote system to a local device.

Encryption

Transforming information so unauthorized readers cannot understand it.

Ethernet

A common technology for wired computer networks.

File System

The method an operating system uses to organize files.

Firewall

A security tool that filters network traffic based on rules.

Firmware

Software stored in hardware that controls basic device functions.

Flowchart

A diagram showing the steps and decisions in a process.

Framework

A collection of reusable tools and structures for building software.

Frontend

The part of a website or application users see and interact with.

Git

A version control tool for tracking changes to files.

GitHub

An online service for hosting and collaborating on Git repositories.

GUI

A graphical user interface with elements such as buttons and menus.

Hardware

The physical parts of a computer system.

Hashing

Converting data into a fixed-length value using a hash function.

HTML

A markup language used to structure web page content.

HTTP

A protocol used to exchange web requests and responses.

HTTPS

HTTP protected by an encrypted connection using TLS.

Hyperlink

A clickable connection to another page or resource.

Input Device

Hardware used to enter data into a computer.

IP Address

A numerical address used to identify a device on a network.

JavaScript

A programming language commonly used to add behavior to web pages.

JSON

A text format used to store and exchange structured data.

Kernel

The central part of an operating system that manages key resources.

LAN

A network connecting devices within a limited area.

Latency

The delay before data begins to travel or a response arrives.

Library

A collection of reusable code that programs can use.

Local Storage

Browser storage that can retain data after the browser is closed.

Login Session

A period during which a system recognizes a signed-in user.

Machine Learning

A field of AI where systems learn patterns from data.

Malware

Software designed to damage systems or perform unwanted actions.

Memory

Storage used by a computer to hold data and instructions.

Metadata

Information that describes other data.

Motherboard

The main circuit board that connects computer components.

Multitasking

Running or managing multiple tasks during the same period.

Network Protocol

A set of rules for communication between devices.

Operating System

Software that manages hardware and supports applications.

Output Device

Hardware that presents information from a computer.

Packet

A small unit of data sent across a network.

Password Hash

A derived value used to verify a password without storing its plain text.

Phishing

A scam that tricks people into revealing information or taking unsafe actions.

Pixel

The smallest individual element of a digital image display.

Port

A numbered endpoint used by network services for communication.

Process

A program that is currently running.

Programming Language

A language used to write instructions for computers.

RAM

Temporary working memory used by running programs.

Repository

A location where project files and version history are stored.

Responsive Design

A design approach that adapts layouts to different screen sizes.

ROM

Memory that typically stores data needed for basic device operation.

Router

A device that forwards data between networks.

Search Engine

A service that finds information on the web.

Semantic HTML

HTML elements that describe the meaning of page content.

Server

A computer or program that provides services to clients.

Session Storage

Browser storage that generally lasts for the current tab session.

Software

Programs and instructions used by computers.

Source Code

Human-readable instructions written by a programmer.

SQL

A language used to manage and query relational databases.

SSD

A storage device that uses flash memory and has no moving disks.

Strong Password

A password that is difficult to guess, often because it is long and unique.

Syntax

Rules for writing valid statements in a programming language.

Thread

A sequence of execution within a process.

TLS

A protocol used to secure data exchanged over a network.

Two-Factor Authentication

Signing in using two different forms of verification.

UI

The controls and visual elements through which a user interacts with software.

URL

The address of a resource on the internet.

USB

A standard for connecting devices and transferring data or power.

User Experience

How a person experiences and interacts with a product or service.

Validation

Checking whether input meets specified rules.

Variable

A named value that a program can store or change.

Version Control

A system for recording and managing changes to files.

Virtual Machine

A software-based computer that runs within another system.

Virus

A type of malicious code that can spread by infecting files or programs.

VPN

A technology that creates an encrypted connection through another network.

WAN

A network that covers a large geographic area.

Web Hosting

A service that makes website files accessible online.

Web Server

Software or hardware that responds to web requests.

Website Maintenance

Updating and checking a website to keep it working properly.

Wi-Fi

A wireless networking technology used to connect devices.

XML

A markup language used to represent structured data.
